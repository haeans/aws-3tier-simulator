==============================================================
 AWS 3-Tier 아키텍처 시뮬레이터
==============================================================

캔버스 위에 AWS 서비스 박스와 영역(VPC/AZ/서브넷)을 배치하고 연결해서,
3-Tier 아키텍처가 논리적으로 성립하는지 검증해 보는 학습용 웹 도구.
실제 AWS 리소스는 만들지 않는다.

- 대상: 개발자 본인(학습/재미), AWS를 처음 접하는 사람
- 형태: 단일 HTML 파일 (HTML + CSS + JavaScript, 외부 라이브러리 없음)
- 환경: 데스크톱 브라우저 (Edge / Chrome 권장)


--------------------------------------------------------------
 1. 실행 방법
--------------------------------------------------------------
aws-arch-simulator.html 파일을 브라우저로 열면 된다. (서버 불필요)

작업 내용은 브라우저 저장소(localStorage)에 자동 저장되므로,
같은 브라우저로 다시 열면 이어서 작업할 수 있다.
다른 브라우저나 시크릿 창에서는 빈 캔버스로 열린다.


--------------------------------------------------------------
 2. 주요 기능
--------------------------------------------------------------
[배치]
- 좌측 팔레트에서 영역/서비스를 끌어다 격자 캔버스에 배치 (격자 스냅)
- 영역 중첩 규칙: VPC > AZ > 서브넷(퍼블릭/프라이빗/DB) > 서비스
- 서비스별 배치 가능 위치 제한 (어기면 안내 메시지와 함께 되돌림)
- 서비스 박스끼리, 같은 단계 영역끼리 겹침 방지
- IGW / VPC Endpoints / Client VPN은 VPC 경계선에 자동으로 붙음
- 영역 크기 조절 (좌상단·우하단 손잡이), 영역 이동 시 안의 항목도 함께 이동
- [기본 틀 불러오기]: VPC 1 + AZ 2 + AZ별 퍼블릭/프라이빗/DB 서브넷

[연결]
- [연결 모드]에서 박스 → 박스 클릭으로 양방향 직각 화살표 연결
- 연결점(변 중앙) 직접 선택, 끝점 손잡이로 연결 변 변경, 가운데 손잡이로 경로 이동
- 자동 경로는 다른 박스를 피해서 그림. 선에 마우스를 올리면 그 선만 강조

[검증]
- [검증하기]: 정상 / 경고 / 오류 3단계 판정 + 문제 박스 강조 (규칙 7개)
- 개선·제거 제안 (판정과 별개, 규칙 7개)
- 검증 후 연결선 위로 흐름 점 표시 (초록=정상, 노랑=병목, 빨강=오류)

[기타]
- 줌 60~150% (버튼 / Ctrl+휠), 자동 저장 (배치·줌·스크롤 위치)
- 서비스·영역 설명 툴팁, 스크롤 중에만 보이는 스크롤바

 3. 파일 구조
--------------------------------------------------------------
aws-arch-simulator.html   프로그램 전체 (아래 구역으로 나뉨)
README.txt                이 문서 (개요 + 변경 이력)
memo.txt                  개인 리뷰 메모

[aws-arch-simulator.html 안의 구역]  (주석 제목으로 검색)
- CSS
- 서비스 데이터 정의 ... 카테고리, 서비스 목록(SERVICES), 영역 목록(AREAS), 설명 문구
- 배치 제한 규칙 ....... PLACEMENT_RULES(서비스 위치), NESTING_RULES(영역 중첩)
- 검증 규칙 ............ VALIDATION_RULES(판정 7개), SUGGESTION_RULES(제안 7개)
- UI·드래그 로직 ....... UI-1 ~ UI-9 하위 구역
    UI-1 상태·공통 유틸        UI-2 소속 판정·동작 검사
    UI-3 팔레트·설명 툴팁      UI-4 추가·삭제·선택·이동·크기 조절
    UI-5 연결선                UI-6 그리기
    UI-7 줌·저장               UI-8 검증 결과 표시·동적 흐름
    UI-9 기본 틀·이벤트·시작

[자주 고치는 곳]
- 서비스 추가 ......... SERVICES 배열에 한 줄 + SERVICE_DESC에 설명 한 줄
- 배치 위치 규칙 ...... PLACEMENT_RULES / 서비스의 allowedZone 값
- 검증 규칙 ........... VALIDATION_RULES 배열에 항목 추가
- 개선·제거 제안 ...... SUGGESTION_RULES 배열에 항목 추가

  추가: 연결선에 마우스를 올리면 그 선과 양 끝 박스 강조, 나머지 선은 흐리게
  추가: 검증 후 연결선 위로 흐름 점 (초록=정상, 노랑=병목/경고, 빨강=오류)

--------------------------------------------------------------
 5. 알려진 제한 사항
--------------------------------------------------------------
- 박스를 끄는 도중 스크롤하면 중간 상태가 저장될 수 있음 (놓으면 정상 저장)
- 박스를 끄는 도중 Ctrl+휠로 줌하면 박스 위치가 튐
- 저장 데이터에 규칙 위반이 들어 있으면 이후 동작이 거부될 수 있음
- 영역 밖으로 반쯤 걸친 박스가 있으면 좌상단 크기 조절 시 영역이 한 번 튐
- 실행 취소(Undo) 기능 없음
