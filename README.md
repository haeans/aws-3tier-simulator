# AWS 3-Tier 아키텍처 시뮬레이터

캔버스 위에 AWS 서비스 박스와 영역(VPC/AZ/서브넷)을 배치하고 연결해서,
3-Tier 아키텍처가 논리적으로 성립하는지 검증해 보는 학습용 웹 도구.
실제 AWS 리소스는 만들지 않는다.

- 최종 목표: IDC(온프레미스)에서 AWS로, 서버에서 서버리스·컨테이너로 옮기는 마이그레이션 과정을
  CI/CD와 함께 설계해 보고, 그 구성의 성능(트래픽 부하·장애·요청)까지 시뮬레이션으로 확인하는 도구
  (2026-10-15 사용자 결정. 진행 순서는 ROADMAP.md)
- 대상: 개발자 본인(학습/재미), AWS를 처음 접하는 사람
- 형태: HTML + CSS + JavaScript 파일 (외부 라이브러리 없음, 서버 없이 실행)
- 환경: 데스크톱 브라우저 (Edge / Chrome 권장)


## 실행 방법
index.html 파일을 브라우저로 열면 된다. (서버 불필요, 더블클릭으로 실행)
css/, js/ 폴더가 index.html과 같은 위치에 있어야 한다. 공유할 때는 폴더째 전달한다.

AWS 공식 아이콘(선택): 저장소에는 아이콘 파일이 없다. 없으면 글자 박스로 보인다.
1. https://aws.amazon.com/architecture/icons/ 에서 "Icon package" zip을 내려받아 압축을 푼다
2. `npm run icons -- <압축을 푼 폴더>` → icons/ 폴더가 생긴다 (Node.js 필요)

작업 내용은 브라우저 저장소(localStorage)에 자동 저장되므로,
같은 브라우저로 다시 열면 이어서 작업할 수 있다.
다른 브라우저나 시크릿 창에서는 빈 캔버스로 열린다.
구성을 보관하거나 다른 사람에게 줄 때는 [파일로 저장]으로 내려받고, [불러오기 ▾] → [파일에서 열기…]로 다시 연다.


## 주요 기능 (요약)
- 배치·연결: 팔레트에서 끌어 놓기, 영역 중첩 규칙, 직각 연결선
- 검증: 정상/경고/오류 판정, 개선·제거 제안, 잘한 점, Well-Architected 근거, 요청·응답 흐름과 단계별 해설
- 비용: 결과 패널 [비용] 탭에서 대략적인 월 비용(서울 온디맨드, AWS 공식 가격 2026-11-13) 내역과 합계, [비교] 탭 비용 줄
- 간단한 설정값: 서버·DB 크기(작게·보통·크게), Auto Scaling 최소·최대·목표 사용률 — 성능 시뮬레이션·비교에 반영
- 라우팅 테이블·보안 그룹: 서브넷을 누르면 라우팅 테이블, 박스를 누르면 보안 그룹 규칙을 그린 구성으로 자동 계산해 설명 패널에 (예시 숫자)
- 구성 두 개 비교: 결과 패널 [비교] 탭에서 지금 구성을 A로 담고, 고친 구성(B)과 판정·트래픽·AZ 장애를 표로 비교
- 면접식 설계 문제: 학습 패널 [문제] 탭에서 요구 사항만 보고 설계 → [제출]로 요구 사항별 채점 → 모범 답안과 비교 (문제 3개)
- 단계별 미션: 툴바 [학습 ◂] → 오른쪽 학습 패널의 [미션] 탭에서 목표를 따라 3-Tier를 만들고, 고치고, 다듬기 (미션 11개, 목표 자동 체크·힌트)
- 성능 시뮬레이션: 트래픽·시나리오·장애 넣기·자동 복구·Auto Scaling·캐시/WAF 효과

자세한 내용은 GUIDE.md 1장.
